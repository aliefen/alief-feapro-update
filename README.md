# ALIEF FEA PRO - update

Installer of **ALIEF FEA PRO** (PT. Alief Energy Utama) for the automatic update of installed copies.

- `latest.json` - version, part list and SHA-256 of the current installer (read by Home > Update).
- `ALIEF_FEAPRO_Setup_x.y.z.exe.001 ...` - the installer in 20 MB parts.
- `GABUNG_INSTALLER.zip` - joins the parts by hand: put everything in one folder, extract, run `GABUNG_INSTALLER.bat`.

The software needs a licence from PT. Alief Energy Utama to run in full mode.
